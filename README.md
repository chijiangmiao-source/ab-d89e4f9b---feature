# 射频切换矩阵控制器 · 规范探测串审计

现场只能向控制器发送**同一串**探测码并读取回执，而控制器上电后可能停在任意内部位置。
本工具判断给定机型（位置集合、2~4 个 ASCII 探测码、每位置每码的确定回执与下一位置）
是否存在一串固定探测序列，使任意两个不同初态产生不同的完整回执串；若存在，给出

1. **最短长度**优先、
2. 同长度按探测码 **ASCII 字典序**选择的唯一规范序列，
3. 并逐步列出每轮后仍未分开的初态对。

若不存在，页面返回**经最小化的反例**：

- 存在观测等价类时：给出最小化（最粗划分）等价类中的初态对，逐码展示相同回执与
  仍在同一等价类的后继，证明它们对任意码串回执恒同；
- 机型本身已最小但无固定串时（自适应可分、预设不可分）：给出 BFS 可达
  “未分对集合”状态族的封闭性证明（每个码要么令某对轨迹重合，要么转入族内另一非空状态）。

## 非侵入辨识复核

现场校准则不能让任一上电位置在诊断结束后停留在别处。页面在普通审计旁提供
**非侵入辨识复核**（普通结论与原有逐轮记录始终保留）：

- 该模式只受理**不超过 7 个位置**的当前机型；超限直接退回说明，不做校验与搜索；
- 寻找同一串固定探测码，使不同初态的完整回执串两两不同，**且整串执行后每个初态恰好
  回到自身位置**（位置映射为恒等）；
- Worker 的搜索状态是复合状态 `(各初态当前所在位置的完整映射, 尚未分开的初态对)`，
  按探测码整体推进映射、剔除本轮回执不同的对、对“回执相同且后继重合”的轨迹剪枝，
  **仅当映射恒等且无未分对时成功**；
- 结果同样最短优先、同长度按 ASCII 字典序裁决，并**逐轮列出位置映射与仍未分开的对**；
- 耗尽可达复合状态仍无终点时，给出闭合搜索范围（每个可达状态在各码下要么轨迹重合作废、
  要么转入族内另一非终态状态）及**未满足的终态条件**（族内恒等态与空对态不重合）；
- 修改任一位置、探测码或定义后，非侵入结论**立即失效**（在途结果作废），普通结论不受影响。

## 算法

核心见 `src/audit.js`（Web Worker 与 Node 测试共用同一份代码）：

- 状态是“当前仍未分开的位置对集合”，以无序位置对上的 BigInt 位掩码表示；
- 对每个探测码精确计算集合变换：回执不同 → 该对本轮分开；回执相同、后继重合 →
  该前缀是死分支（剪枝，绝不误判为成功）；回执相同、后继不同 → 映射为后继位置对；
- 在该状态空间做精确 **BFS**，初始状态为全部位置对、目标为空集；不枚举任何初态的
  响应串，也不假设固定深度；
- 命中目标后沿 `parent` 回溯链复算码序列，再正向逐轮复算每对初态的命运与各初态完整回执串；
- 无解时用 Moore 式分区细化求最粗等价类，或输出封闭状态族结构证明；
- 非侵入复核（`bfsNonIntrusiveSequence`）在复合状态
  `(映射, 初态对掩码)` 上做同样的精确 BFS：初始态 `(恒等, 全对)`，
  目标态 `(恒等, 空对)`；映射以 n 进制数编码、对集合以 BigInt 位掩码编码，
  7 位置复合状态空间有界，实测毫秒~百毫秒级完成。

位置上限 10（45 对）、码 2~4 个，搜索在浏览器的 Web Worker 中运行，不阻塞页面。

## 本地开发

```bash
npm install
npm run dev          # Vite 开发服务器
npm run test:unit    # node --test 单元测试（含 60 组随机机型与暴力预言机对拍）
npm run build        # 构建到 dist/
npm run preview      # 用零依赖静态服务器提供 dist/（含 /healthz）
npm run smoke        # HTTP 冒烟（默认 http://localhost:8080）
npx playwright test  # 浏览器端到端（需先 build + preview，并安装 Chromium）
```

## Docker Compose

```bash
# 启动页面（宿主机端口可用 HOST_PORT 配置，默认 8080）
HOST_PORT=8080 docker compose up -d --build web
curl -s http://localhost:8080/healthz

# 一次性验证服务：单元测试 → 构建检查 → HTTP 冒烟 → 浏览器端到端，结束后报告状态并退出
docker compose run --build verify
# 或：docker compose up --build verify（依赖 web 健康检查通过后启动）
```

`verify` 服务基于 Playwright 官方镜像运行 Chromium，围绕可区分模型、等价反例、
非法输入，以及非侵入复核的成功 / 无解 / 超限三种场景执行浏览器端到端测试；
全部通过时入口脚本输出 `VERIFY_OK` 并以 0 退出。

## 非法输入

缺失转移 / 缺失回执、下一位置未声明、重复位置名、空码表 / 码数不在 2~4、
非 ASCII 或重复探测码、同一格多条非确定定义——全部问题会**合并显示**并清除旧结论。
